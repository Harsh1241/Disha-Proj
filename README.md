# Disha Special Love Webpage ❤️

A beautifully crafted, responsive, animated, and interactive surprise webpage designed for Disha.

## Features ✨
- **Romantic Aesthetic & Floating Hearts**: Live canvas-rendered floating hearts background with smooth animations.
- **Interactive Love Letter Modal**: Secret emotional love note popup with celebration confetti.
- **6 Secret Scratch/Reveal Joke Cards**: Click to uncover cute teasers, inside jokes, and compliments.
- **Interactive Love-o-Meter**: Tap to boost the love bar until it overloads into 120% pure love celebration.
- **Playful "Do You Love Me?" Game**: The "No" button playfully dodges away whenever hovered or tapped.
- **Little Reasons Why**: Clickable sweet reasons with toast notifications.
- **Instant Virtual Hug Generator**: Confetti and warm message on click.

## Vercel Deployment Instructions 🚀

This project is zero-config static and deploys to **Vercel** in 10 seconds:

### Option 1: Drag & Drop (Super Fast - No CLI or Git needed)
1. Go to [vercel.com](https://vercel.com) and login/signup.
2. In your dashboard, click **Add New...** -> **Project**.
3. Drag & drop this `Disha-proj` folder directly or import your GitHub repository once pushed.

### Option 2: Deploying via GitHub
1. Upload this folder to your GitHub repo when ready.
2. Go to Vercel -> **Import Git Repository**.
3. Keep default settings and click **Deploy**.
4. Share the live `.vercel.app` link with Disha! ❤️
